1.Storage and Accessibility: Explain why it is important to store and organise your files efficiently.
Answers: Efficient file storage and organisation make it easier to find, access, and share research materials. It also helps prevent file loss, duplication, and confusion between different versions.

2.File Storage Methods: Explain which data types may require special access controls.
Answers: Sensitive data such as consent forms, interview transcripts, and files containing personal information require special access controls. These files should only be accessible to authorised research team members and stored securely.

4.Under what scenarios, creating a new branch would be useful (2-3 sentences)?
Creating a new branch is useful when you want to develop a new feature, test an idea, or make changes without affecting the main version of the project. It is also helpful when several team members are working on different tasks at the same time.
